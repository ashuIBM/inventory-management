Factory Inventory Management System

Architecture overview — Vue 3 single-page app talking to a FastAPI service that serves in-memory JSON data. No database, no auth.

Tech stack

Frontend
  • Vue 3, Composition API
  • vue-router 4 (history mode)
  • axios
  • Vite 8 dev server
  • No UI library — custom SVG charts, CSS Grid
Backend
  • Python FastAPI
  • Uvicorn on 0.0.0.0:8001
  • Pydantic v2 models
  • Swagger at /docs
Data
  • 7 JSON files in server/data/
  • generate_data.py regenerates them
  • All dates in 2025; quarters hard-coded in QUARTER_MAP
Tooling
  • pytest + TestClient in tests/backend
  • scripts/start.sh / stop.sh
  • .claude/ agents, commands, hooks, skill

Data flow — changing a filter

  1. User picks Time Period / Location / Category / Status in FilterBar.vue.
  2. Value lands in a module-level ref in useFilters.js — shared by every view (singleton).
  3. The active view watches those refs and calls api.getOrders(getCurrentFilters()).
  4. api.js builds query params, skipping any filter set to "all".
  5. FastAPI runs apply_filters() (warehouse / category / status) and filter_by_month() (month or quarter) over the in-memory lists.
  6. Results are validated against the Pydantic response_model and returned as JSON.
  7. The view stores raw rows in refs; KPIs and charts are computed properties derived from them.

Gaps found while exploring

Missing endpoint

api.js calls /api/tasks (GET/POST/PATCH/DELETE) but the server has no tasks routes — causes the 404 in the console on load.

Missing endpoint

/api/purchase-orders is called by the client, and PurchaseOrder models exist in main.py, but no route is defined.

Missing component

Dashboard.vue renders <PurchaseOrderModal> but never imports it, and no such file exists.

Unrouted view

views/Backlog.vue exists but isn't registered in main.js or the nav.
